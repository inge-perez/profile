Direction: editorial-tech dark portfolio with anchored left rail, section context labels, and calm high-contrast spacing.

Depth strategy: borders-first, no heavy shadows, surface hierarchy by subtle tint shift only.

Palette:
- Background: near-black blue
- Accent: cold electric blue
- Text: porcelain white with muted steel secondary hierarchy

Typography:
- Display/body: Bricolage Grotesque
- Labels/meta: IBM Plex Mono

Layout rules:
- Desktop uses fixed left rail for identity, section state, and social links.
- Main content offsets to respect rail; sections include persistent vertical labels.
- Section heads use 2-column editorial split: title block + mono note.

Component patterns:
- Hero uses a two-column editorial split: identity block left, positioning/call-to-action block right.
- About uses manifesto copy + compact facts column.
- Projects use ledger rows with index, title, inline action, summary, and tech line.
- Experience uses editorial rows with left period column and right narrative column.
- Skills use ledger rows with category heading and inline capability list.
- Services use editorial rows with category heading, short narrative, and inline tags.
- Contact closes with a split layout: direct email headline + compact operational panel.

Motion:
- Short fade/slide reveal on scroll.
- No dramatic transforms; hover shifts stay within 1-2px.

Do not use:
- Large drop shadows
- Bright purple gradients
- Floating glassmorphism panels disconnected from layout
